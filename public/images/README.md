# 📸 Images pour la Page d'Accueil

## Image Requise

Placez votre image de fond dans ce dossier avec le nom : **`background.jpg`**

### Spécifications Recommandées

- **Format** : JPG, PNG ou WebP
- **Taille** : 1920x1080 pixels (Full HD) ou plus
- **Poids** : < 500 KB (optimisé pour le web)
- **Sujet** : Éducation, école, élèves, livres, apprentissage

### Suggestions d'Images

- Élèves en train d'étudier
- Bibliothèque moderne
- Salle de classe avec technologie
- Enfants avec des livres/tablettes
- École moderne avec architecture attrayante

### Optimisation

Pour optimiser votre image avant de la placer :

1. Utilisez un outil comme [TinyPNG](https://tinypng.com/) ou [Squoosh](https://squoosh.app/)
2. Réduisez la taille si nécessaire
3. Assurez-vous que l'image est de bonne qualité

### Nom du Fichier

Le fichier doit s'appeler exactement : **`background.jpg`**

Si vous utilisez un autre format, modifiez le chemin dans `app/page.tsx` :
- `background.png` pour PNG
- `background.webp` pour WebP
